## 2. UI 컴포넌트 설계

### 2.1 Navbar (base.html)
```

- **모바일**: 햄버거 메뉴 (Alpine.js)

### 2.2 Hero Section (index.html)
```
┌─────────────────────────────────────────────────────────┐
│                   [파티클 배경]                          │

## 4. 애니메이션 스펙

### 4.1 파티클 배경 (particles.js)
```javascript
// Hero 섹션 canvas 파티클
- 파티클 수: 80개
- 연결 거리: 150px
- 색상: rgba(255, 255, 255, 0.6)
- 마우스 반응: 커서 주변 파티클 밀림 효과
```

### 4.2 스크롤 애니메이션 (AOS)
```javascript
// data-aos 속성으로 선언적 사용
data-aos="fade-up"         // 아래서 위로 fade
data-aos="fade-right"      // 오른쪽에서
data-aos="zoom-in"         // 확대되며 등장
data-aos-delay="100"       // 딜레이 (순차 등장)
```

### 4.3 카운터 애니메이션
```javascript
// IntersectionObserver로 뷰포트 진입 시 트리거
// 0 → 목표값까지 ease-out 커브로 증가
// 소요 시간: 2000ms
```

### 4.4 타이핑 효과 (Hero)
```javascript
// 텍스트 배열을 순서대로 타이핑
const texts = ['물리학과', 'Physics', '자연의 탐구'];
// 타이핑 속도: 100ms/글자
// 삭제 속도: 50ms/글자
```

## 7. 서브 페이지 상세 설계

### 7.1 학과 소개 (about.html)
```
Hero (소제목 배너)
  ↓
학과장 인사말 (사진 + 텍스트)
  ↓
학과 역사 타임라인 (수직 타임라인 컴포넌트)
  1946 → 1970 → 1990 → 2000 → 2010 → 현재
  ↓
교육 목표 & 비전 (아이콘 카드 3개)
  ↓
교육 과정 (탭: 학사 / 석사 / 박사)
```

### 7.2 연구 분야 (research.html)
```
Hero (배너)
  ↓
연구 분야 개요 (6개 카드 그리드)
  ↓
각 분야 상세 섹션 (아코디언 형태)
  - 응집물질물리
  - 나노물리
  - 광학
  - 입자물리
  - 천체물리
  - 계산물리
```

### 7.3 교수진 (faculty.html)
```
Hero (배너)
  ↓
검색 바 + 분야 필터 버튼
  ↓
교수 카드 그리드 (4열 → 모바일 1열)
  [사진] [이름] [직급] [전공] [이메일]
```

### 7.4 연락처 (contact.html)
```
Hero (배너)
  ↓
2열 레이아웃:
  좌: 연락처 정보 (주소, 전화, 이메일, 찾아오는 법)
  우: 카카오맵 임베드
  ↓
문의 폼 (이름, 이메일, 제목, 내용, 제출 버튼)
```
