## 1. 배경 및 목표

### 1.1 배경
- 부산대학교 물리학과(https://phys.pusan.ac.kr) 소개 웹페이지
- 기존 사이트: 구식 UI, 정보 구조 복잡, 모바일 대응 미흡
- 목표: 전문가가 감탄할 수준의 현대적 학과 소개 페이지

### 1.2 목표
- **디자인**: 물리학의 심오함과 현대성을 동시에 표현
- **성능**: FastAPI로 빠른 응답, 정적 자산 최적화
- **UX**: 직관적인 네비게이션, 풍부한 인터랙션
- **반응형**: 모바일/태블릿/데스크톱 완벽 지원

## 2. 기술 스택

### 2.1 백엔드
- **FastAPI** (Python 3.11+): REST API 서버
- **Jinja2**: 서버사이드 템플릿 렌더링
- **uvicorn**: ASGI 서버
- **Python-multipart**: 파일 업로드 지원

### 2.2 프론트엔드
- **Tailwind CSS** (CDN): 유틸리티 퍼스트 스타일링
- **Alpine.js**: 가벼운 인터랙티브 컴포넌트
- **AOS (Animate On Scroll)**: 스크롤 애니메이션
- **Font Awesome**: 아이콘
- **Google Fonts** (Noto Sans KR): 한국어 웹폰트

### 2.3 프로젝트 구조
```
physics-web/
├── main.py              # FastAPI 앱 진입점
├── routers/
│   └── pages.py         # 페이지 라우터
├── static/
│   ├── css/
│   │   └── custom.css   # 커스텀 스타일
│   ├── js/
│   │   └── main.js      # 커스텀 JS
│   └── images/          # 이미지 자산
├── templates/
│   ├── base.html        # 베이스 레이아웃
│   ├── index.html       # 메인 페이지
│   ├── about.html       # 학과 소개
│   ├── faculty.html     # 교수진
│   ├── research.html    # 연구 분야
│   └── contact.html     # 연락처
└── data/
    └── content.py       # 페이지 콘텐츠 데이터
```

## 3. 핵심 기능 및 페이지 구성

### 3.1 메인 페이지 (index.html)

#### Hero Section
- **전체화면 배경**: 우주/입자 물리 관련 파티클 애니메이션
- **타이핑 효과**: "물리학과" 텍스트 애니메이션
- **CTA 버튼**: 학과 소개, 입학 안내로 바로가기

#### 학과 소개 요약 (About Snippet)
- 설립 연도, 교수 수, 연구실 수, 졸업생 수 (카운터 애니메이션)
- 학과 비전 한 줄 요약

#### 연구 분야 카드 (Research Highlights)
- 6대 연구 분야: 응집물질물리, 나노물리, 광학, 입자물리, 천체물리, 계산물리
- 호버 효과 카드 UI

#### 교수진 프리뷰 (Faculty Preview)
- 대표 교수 3-4인 카드 (사진, 이름, 전공)
- "전체 교수진 보기" 링크

#### 최신 뉴스 & 공지 (News)
- 학과 공지사항, 세미나/콜로퀴엄 일정
- 좌우 슬라이드 카드

#### 퀵 링크 (Quick Links)
- 학생 지원 시스템, 도서관, 취업 지원 등

### 3.2 학과 소개 페이지 (about.html)
